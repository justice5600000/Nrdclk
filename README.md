# NerdClock
A desktop clock for linux written in c using x11.<br>
# Usage
Up arrow - make text bigger<br>
Down arrow - make text smaller<br>
Space - fullscreen
# Why?
I have a little linux laptop nas server and i wanted a less resource-intensive way to have a clock on the screen... so i decided to code it myself!
# Warning
Increasing the text size past 16 (pressing up arrow 16 times) will crash the app, please dont do that!!
